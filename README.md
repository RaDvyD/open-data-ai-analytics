# Аналіз відкритих даних (Повітряні тривоги) - Docker Workspace

Цей проєкт демонструє мікросервісну архітектуру для аналізу відкритих даних за допомогою Docker та Docker Compose. Проєкт поділено на незалежні контейнери, які спілкуються через спільну базу даних та томи.

## Структура проєкту
* `data/` - містить вхідний файл `dataset.csv`.
* `db/` - спільний том для бази даних SQLite (`alerts.db`).
* `reports/` - спільний том для збереження згенерованих звітів та графіків.
* `src/` - вихідний код мікросервісів (кожен у своїй папці зі своїм `Dockerfile`).
* `compose.yaml` - головний файл оркестрації контейнерів.

## Опис сервісів
1. **data_load** — зчитує `dataset.csv` та формує базу даних SQLite.
2. **data_quality** — підключається до БД, перевіряє дані на пропуски/дублікати та генерує текстовий звіт.
3. **research** — обчислює базову статистику та зберігає її у форматі JSON.
4. **visualize** — генерує графіки розподілу тривог по областях та їх тривалості (зберігає у PNG).
5. **web** — Flask-сервер, який читає всі згенеровані артефакти та відображає їх через зручний веб-інтерфейс.

## Команди запуску
Для локального запуску всієї системи виконайте одну команду в корені проєкту:
\`\`\`bash
docker compose up --build
\`\`\`

## Перелік портів
* **8000** (локальний) -> **5000** (внутрішній контейнера `web`): використовується для доступу до веб-інтерфейсу через браузер (`http://localhost:8000` або `http://localhost:8080` залежно від конфігурації).
