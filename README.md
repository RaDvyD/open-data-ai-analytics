# Аналіз відкритих даних: Повітряні тривоги в Україні

**Мета:** Проаналізувати історичні дані та розробити алгоритм для прогнозування повітряних тривог.

**Джерело відкритих даних:** API сповіщень про тривоги (https://alerts.in.ua/)

**Гіпотези для аналізу:**
1. Тривалість повітряних тривог має статистично значущу різницю залежно від регіону України.
2. Існує часова закономірність (залежність від часу доби або дня тижня) у кількості оголошених тривог.
3. На основі зібраних історичних даних можна побудувати предиктивну модель для оцінки ймовірності тривоги в конкретному регіоні.
